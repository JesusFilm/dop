# Return & connection flow

Type: prototype
Status: open
Blocked by: 02, 04

## Question

Design what a returning person sees and how pray-er and pray-ee connect. Make a rough prototype (outline or stub UI) to react to.

- **Before the reveal**: what does the return view show when they come back but assignments aren't ready yet? ("Come back after Xam.")
- **After the reveal**: the assigned person's request — shown per the privacy decision (with or without the submitter's name). Warm framing, not just raw text.
- **Connection**: do they act on it privately, or is there a "go find this person" element? (Follows the physical model from ticket 01.)
- **Cookie limits**: what happens if the cookie is gone / different phone? (Feeds the cross-device fallback fog item.)
- **Confirmation loop back**: any "mark as prayed" or is it purely informational?

Depends on the assignment model (what's actually assigned) and privacy rules (what's allowed to be shown).
